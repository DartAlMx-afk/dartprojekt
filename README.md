# AI Text Corrector (Исправление текста с помощью ИИ)

Это приложение позволяет исправлять грамматические, орфографические и пунктуационные ошибки в любом выделенном тексте при нажатии горячей клавиши `Ctrl+G`. Приложение работает полностью локально, используя нейросетевую модель через [Ollama](https://ollama.ai/).

## Требования

- Python 3.8+
- [Ollama](https://ollama.ai/)
- Права администратора (на некоторых системах могут понадобиться для перехвата горячих клавиш)

## Установка и запуск

### 1. Установите Ollama
Скачайте и установите Ollama с официального сайта: https://ollama.ai/download

### 2. Загрузите локальную модель
Откройте терминал или командную строку и выполните команду для скачивания модели (по умолчанию приложение использует `mistral`, но вы можете изменить ее в коде на любую другую):

```bash
ollama run mistral
```
(после загрузки можете закрыть этот процесс)

### 3. Установите зависимости Python
Установите необходимые библиотеки с помощью pip:

```bash
pip install -r requirements.txt
```

### 4. Запуск
Запустите скрипт (в Linux/macOS может потребоваться запуск через `sudo` из-за использования библиотеки `keyboard`):

```bash
python main.py
```

## Как использовать
1. Убедитесь, что Ollama запущена и работает в фоновом режиме.
2. Запустите `main.py`.
3. Выделите любой текст в любом приложении (браузер, блокнот, мессенджер).
4. Нажмите `Ctrl+G`.
5. Приложение скопирует текст, отправит его локальной модели, а затем автоматически заменит выделенный текст на исправленный.
6. Для выхода из приложения нажмите клавишу `Esc`.

## Настройка
Вы можете изменить используемую модель, отредактировав переменную `MODEL_NAME` в файле `main.py`. Например, на `qwen` или `llama3`.
